# ADR 001 — App Name: Kotikassa

**Date:** 2026-06-16
**Status:** Accepted

## Context

The project needed a name that felt personal and on-brand for a Finnish family finance app.

## Decision

Named the app **Kotikassa** — Finnish for "home cash register."

## Consequences

- Warm, memorable, culturally relevant to the primary user base (Finnish-speaking families)
- All i18n keys, package names, and branding use "Kotikassa"
