# Security Policy

Kotikassa handles financial records and receipt images, so deployments must use
private credentials, household-level Row Level Security and private storage.

This public repository is a portfolio snapshot. It contains no production
credentials or personal financial data and should not be treated as a supported
production release.

If you identify a security issue, please report it privately to
chinthaka.chathurka@gmail.com rather than opening a public issue. Do not include
real credentials, receipt images or other personal information in a report.
